# 已验证的坑与处理

| 现象 | 原因/检查 | 处理 |
| --- | --- | --- |
| Edge 检测失败但已登录 | 沙箱本机网络访问被限制 | 合适权限重复同一连接检测，区分权限与登录 |
| 滚完只采到最后几项 | 虚拟 DOM 回收旧卡片 | 每轮累积 ID 集合，保存结束证据 |
| URL 已换却保存上一帖 | SPA 详情渲染滞后 | ID、标题、作者、正文联合核验后保存 |
| 多篇被误判失效 | 导航其实未变化/裸链接不可用 | 检查实际 URL，用当前页面返回的链接 |
| 帖子 ID 识别成作者 ID | profile 路径有两个 ID | 核验末尾帖子 ID，兼容实际路径 |
| 无图或轮播少页 | 懒加载/重复 slide | 触发加载、核对页数，缺失如实标记 |
| 生活帖图全被删除 | 按整帖主题筛全部图 | 每图独立判断主题和相对正文的信息增量 |
| 图文相同术语被当重复 | 只比关键词 | 比较结构、字段、流程与例证是否新增 |
| 模型响应成功但正文为空 | 推理预算耗尽或结构提取失败 | 查 finish_reason/content，按供应商配置修正，只重试失败项 |
| 解析异常掩盖真实空输出 | 正则匹配 None 后直接 .group | 先校验结构，保留脱敏诊断，不丢原错误 |
| Python/bs4 导入莫名报错 | 工作脚本叫 inspect.py，遮蔽标准库 | 避免标准库同名文件，处理自己产生的同名缓存 |
| 编号从旧常量继续导致冲突 | 复用上次博主脚本 | 扫现存、删除历史和预留号，不硬编码起号 |
| 图片处理后扭曲 | CSS 同时固定宽高或拉伸重绘 | 原图不变，height:auto，移动端实测 |
| ingest 报裸 Markdown 错误 | raw 证据被放入 knowledge/site | 所有原始证据移回批次 work/，knowledge 仅正式单篇 |
| 前端只显示 100 项 | API 上限/只缓存第一页 | 遍历全部分页后汇总，检查最后一项 |
| VitePress 找不到根路径图 | Markdown 编译试图模块导入 | 在生成器适配共享静态资源与运行时 img，验证实际路径 |
| 手册生成找不到 knowledge | 从错误 CWD 运行 | 按 package 脚本要求从 apps/web 运行 |
| Windows npm dev 参数丢失 | shell/npm 参数转发差异 | 检查实际命令，必要时显式 node 调 Vite 入口 |
| Copy-Item -LiteralPath path\* 不复制 | LiteralPath 把星号当字面量 | 核对绝对目标后枚举子项或使用明确 copytree |
| 容器启动后仍 unhealthy | 初始向量化超过健康宽限 | 看日志和实际进度，不反复重启或关闭嵌入 |
| 文件已入库却检索不到 | 镜像旧源/运行索引未更新 | 按授权同步运行服务，实际 RAG 查询新文档 |
| 清理原始证据被自动审查拒绝 | 永久递归删除缺少明确授权 | 保留证据，说明拒绝原因；不换 shell、shutil 或先移动再删除 |

日志只输出脱敏错误、数量和规范来源，不输出完整带签名链接、.env、Cookie。单次收集里的作者名、ID、数量、日期、模型、端口和容器名都不能变成复用默认值。

完成报告不能混淆：发现项≠成功笔记，结构校验通过≠全量完成，容器启动≠健康，文件存在≠RAG 命中，本地构建≠远端发布。

## 展示格式的新约束

- 合集从 1 编号不等于把 L31 改成 L01；稳定身份和视图序号分开。先全量排序并编号，再筛选/分页，第 2 页从 10 开始。
- 全集编号不能根据搜索接口子集重算，文件夹篇数也不能用第一页 API 结果推断。
- 精简稿删掉阅读边界章节后，旧 legacy 校验会报错；新批次明确 content_format: concise，模板、正文、验证器保持一致。
- 详情返回后立即检查可能还在加载；等待有效列表就绪再断言，不能先在验收报告写成成功。
- 仅写好 skill 不等于当前应用已应用从 1 展示编号；两种工作分别说明。
