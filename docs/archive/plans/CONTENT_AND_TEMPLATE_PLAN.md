# 用户资料与模板接入

## 实施范围

- [x] 将用户提供的60篇原创研究笔记按来源分类导入知识源；不导入合集重复项，保留原始出处和局限。
- [x] 知识中心增加JD、面经、学习资料三个展览式栏目，卡片打开完整笔记；保留Mock与原有三大业务入口。
- [x] 用户上传JD保持私有，可从JD栏目回看，优先用于本次简历的岗位分析与RAG。
- [x] 后台保留resume_template.tex原件与哈希，制作受控Jinja模板，保持原排版与紫色简历强调色。
- [x] 提取姓名/联系方式及教育、项目、实习、技能等结构映射；所有内容映射回源事实，无法识别的字段留空或进入其他经历，不补造。
- [x] 改写使用当前目标JD和三类知识证据，返回段落建议与依据，人工确认后填入模板生成版本。
- [x] 单元/API回归、前端构建、浏览器检查与更新说明。

已验证本机模板实编译；真实Provider与Docker PDF Worker的环境验证仍见CONTENT_GUIDE。

## 验收

1. 导入统计为30面经+30学习，重复执行不产生重复条目，无独立JD时如实显示。
2. 图库按类型展示并可读全文，来源外链及研究笔记属性清晰。
3. 上传JD仅所有者可见，正文优先于泛化岗位资料，模型请求包含真实检索证据。
4. 提取模型新增事实、漏分或重复分配事实时拒绝接受；模板包含全部确认事实并转义TeX。
5. 教育锁定、授权段落、版本回滚与下载鉴权保持通过。

## 选择

沿用单仓与现有Provider/权限边界。资料仍是Markdown事实源；不用另建三套向量库。不将用户上传JD写入公共知识库。模板是后端受控资源，模型仅返回结构映射与patch，不生成任意TeX。
