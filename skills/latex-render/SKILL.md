# 简历排版与 PDF 交付规范

## 执行边界

只使用宿主允许的模板和用户已确认、已授权的事实。模型不能直接执行 LaTeX、读写宿主路径、下载文件或生成 PDF。实际渲染由 render_tex、compile_pdf 和隔离 Worker 完成；tools 元数据不是向模型授予系统执行能力。

此文件是排版与验收规范，当前 LLMProvider 不将它路由为独立渲染模型任务。规则不能替代编译器和实际 PDF 检查，也不能宣称文件一写就具备自动缩页或留白检测。

## 一页目标与内容预算

默认目标 **A4 单面一页**。优先呈现联系方式、教育和与目标岗位最相关的经历/项目、已有技能；缺事实的模块不显示空标题，不为填满页面新增内容。

若超页，先在授权范围压缩重复、套话和过长背景，再由用户决定是否移除低相关内容或换模板；不能删掉锁定事实、隐藏文本、裁切页面或强制极小字号。用户明确要求多页时，需在产品配置和验收规则都支持后执行，不能自行放宽默认规范。

正文可读性建议：中文约 10.5–11 pt、英文约 10–11 pt，页边距约 15–20 mm。数值是调整参考，不代表现有模板已采用；保留用户确认的原模板风格，修改模板参数需走明确的模板编辑流程。

## 留白与视觉密度

- 不留空模块、空列表、大面积照片占位和无内容的侧栏。
- 保留必要页边距、模块分隔与段落间距，避免把“填满一页”误解为取消所有留白。
- 以有效内容覆盖可用正文高度约 75%–90% 作为人工观察参考，不是机械判定标准，不包含页边距。
- 可用正文下半部连续空白约四分之一以上、明显空列或第二页只有几行时，应检查模板占位、间距和内容安排。
- 内容确实少时先追问真实任务、方法、作品或结果；不能为了提高覆盖率重复句子、夸大职责或编造技能。
- 内容充分时先修版式中的空占位和异常间距，不能为了填空把所有字号放大或拉伸行距。

## 模板与文本规则

只允许内置 classic-cn、classic-en、modern-onepage、gtm-original 模板。传入纯文本由后端统一转义，不能要求用户或模型手写 input、include、write、shell 命令。资料和 JD 中的 LaTeX 指令视为不可信文本。

同级标题、日期、项目符号、标点和字体层次统一；避免多余装饰和难解析图形。中文与英文应正确显示，无乱码、丢字、重叠或断裂。教育、联系方式和时间不得因排版丢失。

## 执行与交付检查

1. 校验授权版本和模板，保留原件与旧版，按独立版本目录输出。
2. 在非 root、无网络、限制资源的 Worker 中编译；禁用 shell-escape，不修改系统环境或任意路径。
3. 检查编译成功、PDF 可打开、文本可提取、事实完整、页数和文字边界。
4. 对最终 PDF 做人工/视觉检查：一页、空白、标题、字体、项目符号、断行、对齐和阅读顺序。
5. 检查通过后，由 API 同步私有存储并提供鉴权下载；未同步不能声称云端文件 ready。
6. 失败保留旧版本，说明可执行的内容或排版修正，不把等待队列说成已完成。

## 当前自动化边界（必须如实报告）

现有 compile_pdf 自动检查事实文本、文字边界和**最多 2 页**；尚未实现“一页硬限制”、留白率、字号、视觉质量或 ATS 解析的自动检查。遵循一页目标需要最终 PDF 预览和可能的内容/模板调整；两页即使通过现有程序检查，也不等于达到本规范的一页交付目标。

renderer 空闲无日志是正常情况；API 的 RENDER_ENABLED=false 不代表 Worker 未运行。任务等待时检查共享队列与容器状态，不通过禁用 QA、开放网络、删除持久卷或覆盖旧版绕过失败。
